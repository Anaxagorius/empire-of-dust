# Empire of Dust — Brutal edition

Single-file idle game. No install.

## Download

1. Grab **Empire-of-Dust.zip** from the latest [Release](https://github.com/Anaxagorius/empire-of-dust/releases/latest).
2. Unzip it.
3. Double-click `Empire-of-Dust.html`.

Or download the HTML directly:

- [Empire-of-Dust.html](https://github.com/Anaxagorius/empire-of-dust/releases/latest/download/Empire-of-Dust.html)
- [Empire-of-Dust.zip](https://github.com/Anaxagorius/empire-of-dust/releases/latest/download/Empire-of-Dust.zip)

Progress saves in that browser (localStorage).

This cut includes wreck-paper crashes, named relics, seasons, desperation, oaths, and Crown.
