# Empire of Dust

Dust-bowl idle clicker as **one HTML file**. No install.

## Download

1. Open the [latest release](https://github.com/Anaxagorius/empire-of-dust/releases/latest)
2. Click **Empire-of-Dust.html** under Assets
3. Double-click the saved file to play in any browser

Progress saves in that browser. You can also export a save from Ledger inside the game.
